## What Was Done

### 1. Fixed zero-padded UNet input (bug fix)

**Problem**: `_reconstruct_image()` placed optimized RF pixels into a zero-padded full image. The UNet (trained on full natural images) received ~79% zeros — out-of-distribution input that biased the Tweedie denoised estimate.

**Fix**: Added `background` parameter to `_reconstruct_image()`. All call sites now pass `x_start` as background, so the UNet sees a full natural image at all times. The GP kernel ignores non-RF pixels regardless (`kernels.py:587-589` masks them internally).

**Conclusion**: Confirmed fix works. Diffusion-guided run with lambda=1.0 showed 0% OOB (vs 48% utility-only). Proj_coeff stayed below 0.5 (vs 6.4 utility-only).

### 2. Unified optimizer to LBFGS

**Problem**: The code had separate SGD (for diffusion-guided) and LBFGS (for utility-only) paths. SGD was chosen because LBFGS failed with the combined objective in the previous session.

**Change**: Merged both paths into a single LBFGS closure. Later improved to proximal/MM pattern: Tweedie target computed once per outer step (outside closure), used as fixed target inside. This ensures function/gradient consistency for the strong_wolfe line search.

**Conclusion**: LBFGS works with the combined objective after the zero-padding fix and proximal pattern.

### 3. Conceptual analysis of diffusion guidance approaches

**Discussion**: Deep dive into what our code actually does vs the LaTeX reference (`diffusion_models_introduction.tex`). Key clarifications:

- Our method is **Approach A** (L2 penalty toward Tweedie estimate), not the score function directly.
- We DO add artificial noise (required for the UNet to function). The UNet cannot process clean images directly.
- The L2 gradient is proportional to `(eps_hat - eps)`, which is the Score Distillation Sampling (SDS) gradient with a different weighting.
- The penalty is adaptive: near-zero for natural images (UNet recovers x well), grows as x becomes unnatural.

**Output**: Created `GUIDANCE_POSSIBILITIES.tex` documenting 4 approaches with tradeoffs:
- **A**: L2 toward Tweedie (current). Cheap, but weak near natural manifold, doesn't prevent norm growth.
- **B**: Direct score with noise. More signal but higher variance.
- **C**: Score without noise (direct evaluation). Theoretically correct but UNet is out-of-distribution.
- **D**: Full guided reverse diffusion. Most principled but expensive (T UNet forward+backward passes).

### 4. Masked vs full-image optimization comparison

**Question**: Does optimizing only RF pixels (with frozen natural content outside) degrade the diffusion regularization due to spatial non-uniformity?

**Setup**: Created `no_masking/compare_masking.py`. For each target image, runs both:
- Masked: optimize ~2500 RF pixels, kernel.use_mask=True (current approach)
- Full: optimize all 4096 pixels, kernel.use_mask=False

**Results** (5 targets, lambda_diff=1.0, arc_cosine kernel, M=50):

| Target | U_masked | U_full | OOB masked | OOB full |
|--------|----------|--------|------------|----------|
| 0 | 0.000003 | 0.0019 | 56% | 74% |
| 10 | 0.000036 | 0.0363 | 51% | 76% |
| 20 | 0.000210 | 0.000009 | 58% | 73% |
| 30 | 0.000038 | 0.0002 | 54% | 74% |
| 50 | 0.007042 | 0.0014 | 51% | 71% |

**Conclusion**: INCONCLUSIVE. Both modes struggle. Full mode consistently has worse OOB (71-76% vs 51-58%) because the diffusion L2 on all 4096 pixels (L_diff ~30-50) overwhelms utility. The comparison needs:
1. Better lambda_diff tuning (current 1.0 is too strong for full mode)
2. Consistent target images and parameter state

## Open Questions for Next Session

1. **Lambda tuning**: lambda_diff=1.0 is too strong for the full-image mode (diffusion L2 on 4096 pixels overwhelms utility). Need to scale lambda inversely with pixel count, or use a different formulation.

2. **Approach D feasibility**: Full guided reverse diffusion (Section 6.3 of the LaTeX) would avoid all the approximation issues of Approach A. Requires backprop through UNet — is this computationally feasible at 64x64?

3. **Reproducibility**: The user's earlier results (saved PNGs) were generated with parameter settings that have since changed. Need a systematic parameter sweep to establish a clear baseline before the masked vs full comparison is meaningful.
